Kurulum

Bunu yalnızca bir kez, bir kişi yapar

1Verilerin tutulacağı özel depo

  1. GitHub'da New repository → ad: apartman-veri → Private seç → oluştur.
  2. Bu klasördeki ozel-repoya-yukle/data.json dosyasını o depoya yükle (Add file → Upload files).

2Erişim anahtarı üret

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Expiration: No expiration (veya 1 yıl).
  3. Repository access: Only select repositories → sadece apartman-veri.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Oluştur ve çıkan github_pat_… anahtarını kopyala.

3Şifrele

Anahtar, belirlediğin şifreyle şifrelenir. Sonrasında sen ve Hakan sadece bu şifreyi kullanırsınız.

4Son adım

Aşağıdaki içeriği projedeki vault.js dosyasının içine tamamen yapıştır, kaydet ve GitHub'a yükle. Bitti.
